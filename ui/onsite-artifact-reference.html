How to connect VoiceStudio
1. Install and open VoiceStudio. Generate one line once so the model is downloaded.
2. In the Claude desktop app, add this to your MCP config (Settings → Developer → Edit config), then restart the app. The name must be voicestudio.
{ "mcpServers": { "voicestudio": { "command": "npx", "args": ["-y", "mcp-remote", "http://localhost:3900/mcp/"] } } }
3. Open this artifact inside the Claude desktop app and tap Connect. It only works there, and only for the artifact’s owner.

Browser voice works anywhere but sounds robotic. VoiceStudio runs on your own machine and sounds natural. If the mic is blocked, you can still type.
