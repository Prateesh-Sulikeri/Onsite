What you get

A full onsite, as often as you want

Whole loops

Pick any rounds: resume screen, project deep dive, fundamentals, DSA, code comprehension, low-level design, system design, behavioral and hiring manager.

Company loops

Onsite researches recent candidate reports for a company and role. Then it runs that company's loop, with its reported questions and interviewer style.

Spoken calls

Speech runs on your machine with the built-in voice engine. No GPU needed. Prefer typing? Every round works typed too.

A real workspace

A code editor with Run and Submit in Java, Python, C++ and JavaScript. A whiteboard for designs, and notes. The interviewer sees what you share.

In the code comprehension round you read a small multi-file project with planted bugs and say what is wrong. The AI writes one for your job description, or you pick a ready-made project.

Honest feedback

Rubric scores with evidence, what to fix first and stronger answers for the key moments. A full loop ends with a hiring-committee verdict.

Resume check

See your resume the way six common ATS products read it. Add a job posting and get a match score and an AI screen of your fit.

Engines

Bring your own AI. Keep your voice local.

Onsite has no account and no server. The AI is the one you connect. Speech runs on your computer.

AI engines

Pick one in Settings → AI model. You choose two models: one for the interviewer and one for reports and research. The model lists load live from each provider.

Voice engines

Default

Built-in

Pocket TTS speaks and Parakeet TDT listens. Both run inside Onsite on your CPU, with no GPU and nothing to install. The models download once from Settings → Voice (about 580 MB). Two voices: Ethan (American) and Charlotte (British).

Optional

VoiceStudio

A separate desktop app. Onsite talks to it on your own machine (localhost). Each interviewer on a panel gets their own voice. Best on Windows with an NVIDIA GPU.

Accuracy pass

Whisper large-v3

On Windows with VoiceStudio and a CUDA GPU, Onsite runs every answer through Whisper as well. It gets terms like Redis and idempotency key right. Without it, Parakeet's text is used.

Three ways to answer: Spoken, Listen (the interviewer speaks, you type) or Typed. If voice can't start, the round goes typed instead of failing. English only for now.

Recommended setup

How to get the most out of it

AI

Claude Code if you already pay for Claude Pro or Max. No subscription? Start with a free Groq or Gemini key.

Voice

The built-in engine and a headset. Keep the answer pause at 3 seconds so a thinking pause doesn't end your answer. You can also tap to finish.

Slow laptop?

If the interviewer pauses mid-sentence, your CPU is struggling with the voice. Pick Listen or Typed on the Get ready screen.

  1. Connect an AI. Settings → AI model: pick one, paste the key, press Run health check.
  2. Get the voice. Settings → Voice: download the models. Skip this for typed rounds.
  3. Start small. One round first. Paste your resume and the job description so the questions fit you.
  4. Talk like it's real. Think out loud and share your code or drawing. The interviewer gives no feedback during the round, and it ends the round when time's up.
  5. Read the report. Start with "Fix this first", then the stronger answers for the key moments.
  6. Go for a real target. Research a company in Dossiers (a few minutes on an API key, 10-40 on Claude Code), then run its whole loop for a hiring-committee verdict.

Opening it the first time

Onsite isn't code-signed yet, so your system warns about it once.

SystemWhat you seeWhat to do
Windows"Windows protected your PC"Click More info, then Run anyway.
macOS"Onsite is damaged" or "can't be opened"Run xattr -dr com.apple.quarantine /Applications/Onsite.app once in Terminal. Allow the microphone when asked.
LinuxThe AppImage won't startRun chmod +x Onsite_*.AppImage.

Check a download against SHA256SUMS.txt. Code signing policy

System requirements

Typed rounds run on any 64-bit computer with 4 GB RAM. Spoken rounds run the voice on your CPU, so the CPU matters most.
