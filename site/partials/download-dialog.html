Before you download

Onsite

Onsite isn't code-signed yet (approval pending), so your system will show a warning. It's safe to continue.

Windows: click More info, then Run anyway.

macOS: run xattr -dr com.apple.quarantine /Applications/Onsite.app once in Terminal.

Linux: run chmod +x Onsite_*.AppImage first.

Open source, built by GitHub Actions, no tracking.
